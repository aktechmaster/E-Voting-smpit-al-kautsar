Hubungkan ke Google Sheets & Sesuaikan Data Calon

Masukkan Web App URL yang dipublikasikan dari Google Apps Script.

Kode Google Apps Script (Copy-Paste) 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // Header otomatis jika sheet masih kosong
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Waktu", "ID Calon", "Nomor Urut", "Nama Calon"]);
  }
  
  sheet.appendRow([
    new Date(),
    data.candidateId,
    data.candidateNumber,
    data.candidateName
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. Buka Google Sheets baru → pilih menu Extensions > Apps Script.
  2. Hapus kode bawaan dan Paste kode di atas.
  3. Klik Deploy > New Deployment → pilih Web App.
  4. Set "Who has access" menjadi Anyone (Siapa Saja) → klik Deploy.
  5. Salin Web App URL dan tempelkan ke kolom input di atas.
